# Prompt para el logo de LinGoXiC

Documento con los prompts listos para copiar y pegar en un generador de imágenes por IA (Midjourney, DALL-E, Ideogram, Leonardo, etc.).

## Identidad visual de la marca

- Nombre: **LinGoXiC**
- Colores de la app: gradiente **sky → emerald** (azul celeste → esmeralda) como acento principal.
- Fondo de pantallas iniciales: gradiente **índigo → violeta** (azul profundo → morado).
- Público: estudiantes de secundaria (12-18 años) de Costa Rica, nivel A1-B2.
- Connotación del nombre: lenguaje (Lin) + avanzar (Go) + la X como punto de encuentro entre el estudiante y el idioma.

## Prompt principal (emblema con nombre)

> Minimalist flat logo emblem for "LinGoXiC", an English learning app for high school students. Symbol: a speech bubble formed by an interlocking letter "L" and letter "X" in the negative space. Gradient from sky blue to emerald green. Clean geometric shapes, smooth rounded corners, white background, no text other than "LinGoXiC" in a bold modern sans-serif font below the symbol. Professional, modern, friendly for teenagers. Flat vector style, high contrast, crisp edges.

## Notas de uso

- Genera en **cuadrado 1:1** para ícono de app y favicon; en **horizontal** para header/sidebar.
- Pide **fondo blanco o transparente** en la variante principal; **transparente** para el favicon.
- Colores hex de la marca:
  - Sky (azul celeste): `#0EA5E9`
  - Emerald (esmeralda): `#10B981`
  - Indigo (azul profundo, fondo): `#4F46E5`
  - Violeta: `#8B5CF6`
- Si el generador lo permite, usa el prompt principal y luego pide "transparent background, vector, PNG".
- Para el favicon/ícono usa la variante "solo símbolo" (sin texto), porque a 16-192 px el texto no se lee.
